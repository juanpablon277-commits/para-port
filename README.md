💰 Controle de Gastos

Aplicação web desenvolvida para gerenciamento financeiro pessoal, permitindo o controle de receitas e despesas de forma simples, organizada e intuitiva.

O projeto foi criado com foco em prática de desenvolvimento frontend, autenticação de usuários, manipulação de dados e integração com banco de dados em nuvem utilizando Firebase.



🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript 
- Firebase Authentication
- Cloud Firestore

  
✨ Funcionalidades

- Autenticação
- Cadastro de usuários
- Login
- Logout
- Recuperação de senha
- Persistência de sessão

🎯 Objetivo do projeto

O principal objetivo deste projeto foi praticar a construção de aplicações web interativas utilizando JavaScript puro, além de desenvolver conhecimentos em autenticação, persistência de dados e organização de aplicações frontend.
